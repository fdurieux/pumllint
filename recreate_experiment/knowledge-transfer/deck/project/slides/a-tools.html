One row per layer in its specified form, with the register spanning them all. Every check certifies form, completeness and consistency. None certifies that a rule is right. The contracts row is the interface form of the architecture layer: an OpenAPI or JSON Schema contract is grounded only when a test that was not derived from the code checks it against the running system. A contract generated from code annotations inherits the code’s defects, as the data contract did in the timestamp case. The numbers are from the degradation test: five degraded copies of the specification kit with three planted defects each, rebuilt by fresh agents while the original and the defect list were off the disk. Every defect that propagated passed the kit’s own tests and failed the pristine ones. The trace gate caught a requirement left without a test, and the decision-table check caught deleted rows. Nothing automated caught a wrong value.
