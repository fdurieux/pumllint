What exists can be recovered and measured. For behaviour, the code is the truth.

Input

One code base

About 3 500 lines of a real, operated data program. No documentation and no tests were given to the AI agent.

Output of reverse engineering

A specification kit

158 requirements, 14 contracts, 8 diagrams and 95 executable scenarios, all written from the code alone.

Result of the rebuild

Identical, cell for cell

Two other agents rebuilt the program from the kit alone. Every output the harness could observe matched the original.

What diverged had never been specified: help text and one error path. The architecture diagrams changed no behaviour but fixed the module layout and the interfaces, which is the knowledge that layer holds. One program, one domain, single runs.

Source: the recreation experiment, pumllint repository, 2026-10-23

4

This is the evidence for the claim. The experiment ran the round trip code to specification to code on a real program, graded by the original. The reverse engineer and the rebuilders were separate AI agents with no shared memory. The caveat matters: the program was well commented and written with pinned messages and arithmetic, so the result says more about that program than about reverse engineering in general.
