The cascade runs both ways, and we measured both

Downstream

A gap upstream arrives in the code as a decision

Fifteen defects were planted in the upstream layers of a specification: requirements, contracts, decision tables, diagrams and test scenarios. Six reached the rebuilt code. Which ones was decided by the layer the builder trusted most. A rule deleted everywhere was rebuilt without the rule and recorded as an assumption, not filled in by guesswork.

Defects planted only in the architecture diagrams reached nothing, because the contracts and scenarios carried the behaviour. A gap in architecture knowledge hides behind the layers that carry behaviour.

Upstream

A defect in the code flows back into its documents

A library update changed a stored timestamp from milliseconds to seconds. The comment, the data contract and the generated wiki still said milliseconds. The specification read from the code said seconds. One defect reached two sets of documents in opposite directions.

The original crashed when exporting a missing series. The specification derived from the code recorded the crash as required behaviour. The rebuild reproduced it, and tests calibrated on the same code scored it as correct.

Therefore every captured claim, at every layer, keeps one of three labels: observed in an artefact, inferred by someone, or intended by the business. A defect kept on purpose is a recorded decision, never an accident.

Sources: the degradation test (2026-10-29) and a causal model of artefact quality tested against the experiment (2026-10-28)

A causal model of how artefact quality cascades into product quality was tested against the experiment. Its main path is the downstream cascade on the left, and the degradation test confirmed it with one refinement: what propagates is decided by which layer the builder trusts, not by failing tests. The model’s gap was the right-hand side. As drawn, it runs only from intent to code, and the experiment measured defects running the other way. When the tests are calibrated on the same code, inheritance looks like a passing grade. This is why every layer needs the three labels and a check that does not come from the layer it validates.
